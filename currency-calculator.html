Click any currency field and start typing — you can search by currency code (e.g., "USD"), currency name (e.g., "Dollar", "Taka", "Rupee"), or symbol. The list filters instantly as you type.

Rates are fetched from a live API and updated whenever you click "Refresh Rates" or reload the page. Rates are typically updated daily by the data provider.
